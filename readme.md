1. what is transfomers in mml
 A transformer is a deep learning neural network architecture designed to process sequential data—such as text or audio—by tracking relationships and context across all elements in a sequence simultaneously.
Introduced in the seminal 2017 paper Attention Is All You Need by Vaswani et al., transformers replaced older sequential models like Recurrent Neural Networks (RNNs) and LSTMs. They form the foundational engine behind modern generative AI tools like ChatGPT, Claude, and Gemini.
