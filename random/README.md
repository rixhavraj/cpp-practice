Kubernetes (often abbreviated as K8s) is an open-source container orchestration platform originally developed by Google and now maintained by the Cloud Native Computing Foundation (CNCF).  It automates the deployment, scaling, and management of containerized applications across clusters of virtual or physical machines. 

By acting as the "operating system" for clusters, Kubernetes solves the complexity of managing hundreds or thousands of containers in production. It provides a declarative configuration model where engineers define the desired state of their applications, and the system continuously works to reconcile the actual state with that goal.
